# DocExpire Frontend

React-based web interface for DocExpire document management system.

## Features
- User authentication
- Drag-and-drop file upload
- Document processing and date extraction
- AI-powered analysis
- Cloud storage integration
- CSV export
- Audit log (admin only)

## Quick Start
```bash
npm install
npm run dev
```

Frontend will be available at http://localhost:5173

## Build for Production
```bash
npm run build
```
